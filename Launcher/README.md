# Lunacy Launcher 2.1.0

Фирменный Minecraft-лаунчер для Lunacy Visuals в стилистике сайта `lunacyvisual.fun`.
Electron + Node.js, авторизация через API `https://lunacyvisual.fun`.

## Что нового в версии 2.1.0

1. **Полная очистка Мастерской (Native Modrinth 2.0)**:
   - Полностью убраны сторонние зеркала и ключи (**CurseForge** и **Modrinth.black**).
   - Прямая работа с официальным каталогом Modrinth v2 без необходимости вводить API-ключи.
   - Фильтры по категориям (Оптимизация, Графика, Утилиты, Интерфейс и др.), гибкая сортировка, просмотр описания модов и галереи скриншотов в модальном окне.
   - **Включение / отключение модов**: переключатель активности мода в 1 клик (переименование `.jar` <-> `.jar.disabled`) без необходимости удалять файл.
   - **Импорт файлов и Drag & Drop**: быстрое перетаскивание `.jar` и `.zip` файлов прямо в окно лаунчера с автоматической сортировкой по папкам сборки.
2. **Интерактивные визуальные эффекты и 3D**:

   - **3D скин-подиум**: персонаж игрока в полный рост на неоновом пьедестале с интерактивным 3D-наклоном и вращением по курсору.
   - **Пресеты визуала**: переключатель графических стилей прямо на главном экране (⚡ Lite, ✨ Balanced, 🔥 Ultra, 💎 Cinematic).
3. **Мониторинг серверов Minecraft**:
   - Встроенный TCP-клиент проверки статуса серверов по протоколу Minecraft SLP.

4. **Интеграция с Discord (Rich Presence)**:

5. **Встроенная галерея скриншотов**:

6. **Глобальное обновление Настроек (Settings 2.0)**:

## API сайта, которое использует лаунчер

| Назначение | Запрос |
| --- | --- |
| Вход | `POST /api/auth/login` |
| Регистрация | `POST /api/auth/register` |
| Профиль и подписка | `GET /api/auth/me` (Bearer) |
| Ключ активации | `POST /api/auth/redeem` |
| Версии и загрузчик | `GET /api/client/info` |
| Мод (премиум) | `GET /api/client/download/mod/file` (Bearer; 401 «Войди снова», 403 «Нет подписки») |
| FREE-сборка | `GET /api/client/download/free/file` |
| Обновление лаунчера | `GET /api/client/download/launcher/file` (без подписки) |

Мод скачивается zip-ом, распаковывается в `mods` игровой папки.

## Раскладка файлов мода на сервере

Сейчас в `downloads/mod` и `downloads/launcher` лежат только `README.txt`, поэтому сервер отдаёт 404 «Мод не найден». Залей файлы так:

```
downloads/
  mod/
    lunacy-visuals-mod.zip          # версия по умолчанию
    1.21.11/lunacy-visuals-mod.zip
    26.1.2/lunacy-visuals-mod.zip
    26.2/lunacy-visuals-mod.zip
  free/lunacy-visuals-free.zip
  launcher/lunacy-launcher.zip
```

Лаунчер шлёт `?mc=<версия>`. Чтобы сервер отдавал версию по параметру, в `resolveDownload(kind)` добавь ветку: если `req.query.mc` есть и файл `mod/<mc>/lunacy-visuals-mod.zip` существует — отдать его, иначе файл по умолчанию. Список версий берётся из `config/app.json → client.mcVersions`.

## Вход по лицензии Microsoft

По умолчанию используется публичный client id Minecraft. Свой можно подставить переменной окружения:

```bash
set LUNACY_MS_CLIENT_ID=<твой client id из Azure>
```

Приложение в Azure: тип «Public client / native», разрешён device code flow, scope `XboxLive.signin offline_access`.

## Структура

```
src/main/
  main.js        точка входа, всё IPC
  config.js      адреса API
  http.js        запросы с ретраями и понятными ошибками
  lunacy-auth.js login / register / restore / refresh / redeem
  msauth.js      лицензия Microsoft (device code, Xbox Live, XSTS, профиль)
  store.js       настройки, аккаунты, сессия
  system.js      ОЗУ, Java, видеокарты
  minecraft.js   установка Vanilla / Fabric / Forge и сборка команды запуска
  downloads.js   загрузка мода, FREE-сборки и лаунчера
  catalog.js     Modrinth / Modrinth.black / CurseForge
  updater.js     проверка и установка обновления лаунчера
  game.js        запуск игры
  unzip.js       распаковка zip без внешних зависимостей
src/preload.cjs  безопасный мост в рендерер
src/renderer/    интерфейс (index.html, styles.css, app.js)
```

Файлы пользователя: `userData/lunacy-session.json` (права 0600), `settings.json`, `accounts.json`. Игровая папка по умолчанию — `%APPDATA%\.lunacy`.

## Что нового в v6

**Вход по лицензии Microsoft.** По умолчанию используется классический device-flow Minecraft через
`https://login.live.com/oauth20_connect.srf` (scope `service::user.auth.xboxlive.com::MBI_SSL`, билет `RpsTicket: t=...`).
Именно поэтому раньше была ошибка `AADSTS700016` — классический client id нельзя отправлять
на `login.microsoftonline.com`. Если есть своё Azure-приложение, задай `LUNACY_MS_CLIENT_ID` — лаунчер
автоматически переключится на MSAL-режим (scope `XboxLive.signin offline_access`, билет `d=...`).

**Менеджер версий.** Два виджета — «Версия с визуалом» и «Обычные версии». У каждого большая
кнопка «Версия игры» → открывается модальное меню с плитками версий (арт под загрузчик:
травяной блок — Vanilla, ткань — Fabric, металл — Forge, зелёное свечение — Lunacy) и поиском.
Выбранная версия хранится в настройках и остаётся активной до смены.

**Списки Fabric / Forge.** `versions:remote` теперь всегда отдаёт `{ kind, items, builds }`:
`items` — версии игры, `builds` — сборки загрузчика (Fabric Loader / Forge). Раньше Fabric API
возвращал `{ games, loaders }`, а рендерер ждал массив — поэтому списки были пустые.

**Мастерская 2.0.** Карточки с иконкой, описанием, автором, категориями и числом загрузок. Контент грузится сразу при входе во вкладку (топ по загрузкам), поддерживаются фильтры по категориям (Оптимизация, Графика, Утилиты, Интерфейс и др.) и сортировка.
- Полная интеграция с официальным **Modrinth v2** — работает мгновенно и без ключей.
- Просмотр подробностей о проекте и скриншотов по кнопке «Подробнее».
- Прямая установка в выбранную сборку в 1 клик.

## Консоль и логи (v7)

- Вкладка **Консоль** — весь вывод лаунчера и игры: фильтр, режим «только ошибки»,
  автопрокрутка, копирование и кнопка «Файл логов».
- Файлы логов лежат в `%APPDATA%/Lunacy Launcher/logs/`:
  - `launcher-latest.log` — действия лаунчера;
  - `game-latest.log` — полная команда запуска и весь вывод Java.

Команды для диагностики:

```bash
npm run start:debug   # запуск с выводом логов в терминал
npm run logs          # последние 200 строк обоих логов
npm run logs -- -f    # следить за логами в реальном времени
```

На Windows для подробного вывода в консоль терминала: `set LUNACY_DEBUG=1 && npm start`.

## Запуск игры: что проверяется автоматически

Перед стартом лаунчер:

1. Сверяет список библиотек из профиля с фактическими файлами и `client.jar`.
2. Проверяет реальную версию Java (`java -version`) против `javaVersion.majorVersion` версии.
3. Распаковывает нативы и собирает classpath без дубликатов (главная причина «кода 1» у Fabric/Forge).
4. При выходе с ошибкой разбирает вывод и пишет причину по-русски (старая Java, конфликт модов,
   нет библиотек, мало RAM, драйвер GPU и т.д.).

Кнопка **«Проверить и починить»** во вкладке «Менеджер версий» докачивает недостающие библиотеки,
ассеты и `client.jar`, заново распаковывает нативы. Библиотеки тянутся с зеркал: Mojang, Forge,
NeoForge, Fabric, Quilt, Maven Central.
